# Lab 1: FSD Simulation on Kigali Roads

Full Self Driving (FSD) road simulation using Python from ALU Rwanda to the Kigali Convention Center.

## Project Files
The main simulation code is located in - road_simulation.py, which includes the validation of the signs, the setting of speed limits, the braking and acceleration of the vehicles in the simulation, zebra crossing stops and journey summaries.
- The transit_program.py: Main menu interface.
-The transit_program.py: Simulation runner.
- The engine.py: Simulation engine and local web server.
- The index.html: Web-based graphic representation of the Kigali road.
This is an automatically generated trip log file, created in: - transit_session.log.
-The analyze_log.sh: Bash script summarizes the trip logs.

## How to Run
1.Open a terminal in the project folder.
2.Run the file python road_simulation.py
Go back to the driver's name, press 5  for Start driving , and open the port number you will see in the terminal in your web browser or browser of choice for me I cjose chrome: `http://127.0.0.1:8000`
